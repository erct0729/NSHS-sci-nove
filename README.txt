SCI-NOVE | Science in Noveleta: Observation, Verification, and Exploration
Grade 11 General Science — Noveleta Senior High School

START HERE
1. Extract the ZIP archive.
2. Open index.html in a modern desktop or mobile web browser.
3. Navigate through Home, Learning Hub, Investigations, Challenge Lab, and About.
4. For Google Sites setup, read GOOGLE_SITES_SETUP_GUIDE.md.
5. For native Google Sites page text, read SITE_COPY_PACK.md.
6. To add the five-question sample quiz as an Embed code block, use google-sites-quiz-embed.html.

WHAT WORKS
- Responsive page navigation
- Three complete short sample lesson pages
- Four investigation missions and downloadable text field-note templates
- Instant-feedback five-question assessment and evidence mini-checks
- Local completion markers and highest assessment score
- No external CSS, JS, font, image, server, or third-party account needed

WHAT IS NOT INCLUDED
- No published Google Site or school login
- No automated Google Forms/Sheets or teacher dashboard
- No actual location-specific scientific measurement datasets
- No central student progress or grade submissions

Local progress is saved only in the current browser. A shared browser may have shared progress. Clear progress on the About page.

SCI-NOVE is an educational pilot prototype; review contents, school approvals, curriculum alignment, and data privacy before classroom rollout.
